What is Tekton?

Tekton provides Kubernetes-native building blocks for CI/CD pipelines. Define your build, test, and deploy workflows as code using reusable, composable Steps, Tasks, and Pipelines that run as containers in your cluster.

Simple by Design

A Tekton Task is just a series of steps, each running in its own container. Combine tasks into pipelines. Trigger them from events. It's Kubernetes resources all the way down.

Try the tutorial 
apiVersion: tekton.dev/v1
kind: Task
metadata:
  name: build-and-push
spec:
  params:
    - name: image
  steps:
    - name: build
      image: gcr.io/kaniko-project/executor
      args:
        - --destination=$(params.image)
        - --context=.

The Tekton Ecosystem

A modular set of components — use what you need, skip what you don't.

Pipelines

Define and run CI/CD workflows as Kubernetes resources. The core building block.

Triggers

React to events from Git, webhooks, or any source to start pipeline runs automatically.

Chains

Automated supply chain security. Sign, attest, and verify your builds for SLSA compliance.

Dashboard

Web-based UI to monitor and manage pipeline runs, tasks, and resources.

CLI

Powerful command-line interface to interact with Tekton from your terminal.

Pruner

Automatically clean up completed PipelineRuns and TaskRuns based on retention policies.

Operator

Manage installation, upgrades, and lifecycle of all Tekton components on your cluster.

Results

Long-term storage for pipeline execution history, logs, and metadata beyond cluster retention.

Pipelines as Code

Define pipelines in your Git repository. Native integration with GitHub, GitLab, and Bitbucket.
